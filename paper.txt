• Reorient it consistently, for example to RAS.
• Remove empty background.
• Resample every scan to the same voxel spacing and shape.
• Clip extreme intensities using training-set percentiles.
• Normalize intensity within the brain or striatal region.

template before extracting features.
3. Build biologically meaningful features
A strong first model is usually an ensemble of interpretable regional features and image-
based features rather than a small CNN trained from scratch.
For each scan, calculate:
• Left and right striatal mean uptake.
• Left and right caudate uptake.
• Left and right putamen uptake.
• Regional standard deviations and quantiles.
• Left-to-right asymmetry.
• Putamen-to-caudate ratios.
• Striatum-to-background ratios.
• Posterior-to-anterior putamen ratios.
• Total striatal uptake.
• Voxel-count or volume measures above several intensity thresholds.
• Histogram, texture, and shape features from the striatal masks.

If reliable segmentation is unavailable, create several fixed-size central crops and compute 
the same statistics from each crop.
4. Train strong tabular base models
Use several models with different inductive biases:
• CatBoost or LightGBM on regional and radiomic features.
• Logistic regression with elastic-net regularization.
• XGBoost on selected regional features.
• A small multilayer perceptron only after establishing a strong tabular baseline.

6. Use fold-wise model ensembling
Generate OOF predictions from the tabular and image models. Then combine them using a

7. Calibrate the probabilities
A model can have excellent AUROC but poor log loss because its probabilities are too 
extreme. Fit calibration on OOF predictions:
from scipy.special import expit
from scipy.optimize import minimize_scalar
import numpy as np
def logloss_temperature(T, logits, y):
    p = expit(logits / T)
    p = np.clip(p, 1e-6, 1 - 1e-6)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
temperature = minimize_scalar(
    logloss_temperature,
    bounds=(0.25, 5.0),
    method="bounded",
    args=(oof_logits, y)
).x
calibrated_oof = expit(oof_logits / temperature)
Temperature scaling preserves the ranking and therefore usually preserves AUROC while 
improving log loss.
Also test a small probability shrinkage toward the training prevalence 𝜋:
𝑝shrunk = (1 − 𝜆)𝑝 + 𝜆𝜋.
Optimize 𝜆 on OOF predictions only. This can substantially improve log loss when the 
classifier is overconfident.

Example normalization:
import numpy as np
def normalize_volume(volume, low=-1000, high=1000):
    volume = np.nan_to_num(volume)
    volume = np.clip(volume, low, high)
    volume = (volume - low) / (high - low)
    return volume.astype(np.float32)
For MRI, fixed Hounsfield-unit limits are inappropriate. Use robust percentile normalization 
estimated only from the training fold:
def robust_normalize(volume):
    volume = np.nan_to_num(volume).astype(np.float32)
    p_low, p_high = np.percentile(volume, [1, 99])
    volume = np.clip(volume, p_low, p_high)
    mean = volume.mean()
    std = volume.std() + 1e-6
    return ((volume - mean) / std).astype(np.float32)
If the anatomy occupies only a small region, use a body or foreground mask before resizing. 
Background-dominated volumes often produce poor likelihood and AUROC.

from sklearn.impute import SimpleImputer

from sklearn.model_selection import StratifiedKFold
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler
from sklearn.linear_model import LogisticRegression
# Load the complete dataset

target_column = "target"
id_column = "id"

    include=["int16", "int32", "int64", "float16", "float32", "float64"]

    include=["object", "category", "bool"]
).columns

        ("imputer", SimpleImputer(strategy="most_frequent")),
        ("onehot", OneHotEncoder(handle_unknown="ignore")),

    transformers=[
        ("numeric", numeric_pipeline, numeric_columns),
        ("categorical", categorical_pipeline, categorical_columns),
    ]
)

    steps=[

        (
            "classifier",

    shuffle=True,
    random_state=42,

1. Metric interpretation
The two targets measure different properties:
• AUROC measures ranking quality. A model can have high AUROC while its probabilities are 
poorly calibrated.
• Out-of-fold log loss measures the quality of predicted probabilities. It strongly penalizes 
confident incorrect predictions.
Therefore, optimizing AUROC alone will not reliably produce an OOF log loss below 0.25.
2. Use leakage-free stratified OOF predictions
All preprocessing, feature selection, imputation, encoding, and model fitting must occur 
inside each training fold. Never fit these steps on the complete dataset before generating 
OOF predictions.

3. Build a strong validation scheme
Use the same folds for every experiment. Changing the folds between experiments makes 
leaderboard comparisons unreliable.
For imbalanced classification:
• Use StratifiedKFold.
• Preserve the same random_state.
• Ensure every fold contains both classes.
• Do not use oversampling before splitting.
• If oversampling is necessary, apply it only to each training fold.
For grouped or time-dependent data, use group-based or chronological splits instead. 
Random stratification can cause leakage when observations from the same subject, device, 
or event appear in multiple folds.

5. Improve probability calibration
If AUROC is already above 0.93 but log loss is above 0.25, the ranking is likely adequate and 
the probabilities need calibration.
A simple post-processing approach is temperature scaling:
from scipy.special import expit, logit
from scipy.optimize import minimize_scalar
from sklearn.metrics import log_loss
eps = 1e-7
p = np.clip(oof_probability, eps, 1 - eps)
logits = logit(p)
def temperature_loss(log_temperature):
    temperature = np.exp(log_temperature)
    calibrated_probability = expit(logits / temperature)
    return log_loss(y, calibrated_probability)
result = minimize_scalar(
    temperature_loss,
    bounds=(-3, 3),
    method="bounded"
)
temperature = np.exp(result.x)
calibrated_oof_probability = expit(logits / temperature)
print("Temperature:", temperature)
print("Calibrated log loss:", log_loss(y, calibrated_oof_probability))
print("Calibrated AUROC:", roc_auc_score(y, calibrated_oof_probability))
Temperature scaling changes the confidence of the predictions but preserves their ordering. 
Consequently, AUROC remains essentially unchanged while log loss may improve 
substantially.
Other calibration methods include:
• Platt scaling
• Isotonic regression
• Beta calibration
Calibration must itself be fitted without using the validation labels from the same fold. A safe 
approach is nested cross-validation or a separate calibration split.

Before attempting to reach the target, verify the following:
• The positive-class probability is being submitted: predict_proba(...)[:, 1].

• Scaling is performed within the pipeline.
